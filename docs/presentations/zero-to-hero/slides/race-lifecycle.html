EventManager is a GameObject that owns the race lifecycle. It loads the track's env and scn data, then creates the race object by mode: mode 0 is BaseQuarryEvent and mode 2 is NationalRace, which adds runway lights. Races end on a hard 315-second cap or per-mode finish rules, with 30 or 120 second grace periods online. Replays save as Record\scene_racer_date_time.vcr, and ghosts as .gho in mode 4. The podium uses Winner.mcf, Podium motions and CrowdLoop.wav. The QuarryStuntEvent loader is 7,952 bytes and budgets textures from video memory using MarginPercentage and MinMarginKBytes settings. ProCircuit is the career mode the designers described as keeping your cash flow above zero.
