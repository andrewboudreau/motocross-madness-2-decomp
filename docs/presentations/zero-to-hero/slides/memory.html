09

Memory accounting was clearly important on 64 MB machines. MemTagStack has 15 labels: 3DObjects, Audio, BikeRace, Collision, DebugOverlay, EcoSystem, Particles, QuadTree, Scene, Shadow, Sky, Startup, Terrain, TextureCache and UI, with "Unclaimed" at the root. BlockAllocator is a 40-byte pool; the decomp preserves quirks like an uninitialized allocatedBytes field and a Clear that frees only the active chain. AgeManager is the cache-eviction policy shared by terrain, eco-system and textures. A fun consequence for decompilation: DebugMalloc and operator new take __FILE__ and __LINE__, and those line numbers are compiled in as immediates, so the reconstructed files must place each allocation on the original line.
