07

The architecture is classic year-2000: a PeekMessage loop that calls one virtual "tick" per iteration. The update slot measures time with the CPU timestamp counter and stores the scaled delta as frameTime. Update and render are both virtual calls dispatched down the GameObject tree, which we'll look at next. The render slot times each phase and the wait for flip, and feeds the DebugOverlay profiler and memory pages. Note "slot" numbers are vtable indices; original method names aren't recovered.
