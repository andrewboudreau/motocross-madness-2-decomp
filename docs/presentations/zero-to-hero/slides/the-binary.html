Before reading any function, the PE file itself tells a story. The Rich header shows 197 C++ objects compiled with VC6 build 8447. "/O2 without /G6" is the only compiler-flag family that matches every calibration target, which the docs call the best-supported working hypothesis, not proof. The debug asserts and allocation tags embed __FILE__ paths, which recovered the original folder name, krusty2. Krusty is also the class prefix on KrustyBike, KrustyUI and KrustyVCR; calling it "the Krusty engine" is an inference. Alphabetical link order is the single most useful fact for attributing functions to source files.
