The physics core uses a fixed-step accumulator so the simulation stays stable at any frame rate: it counts how many whole steps fit in the elapsed time plus the leftover remainder, caps the count per frame, and if less than one step has elapsed it runs a single variable-length step instead. The code on the slide is a simplified paraphrase; method names are reconstruction names. Gravity is 32.2 in SelectiveGravityModel, and the same constant appears in a load-weight ratio and a camera formula. Reading it as feet per second squared is an inference. Vehicle::LoadVehicle sets max lean 40 degrees and max lean rate 120 degrees, both multiplied by 0.01745329 to radians, and builds a gearbox from GearRatios.cpp. Glenn O'Bannon was the lead programmer on physics and gameplay.
