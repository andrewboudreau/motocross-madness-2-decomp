This is the "hero" part: how you prove reconstructed code is the original. The match contract says "exact" means every byte in the function's extent matches after relocations are resolved, and each relocation must be independently supported by a per-file bindings.json mapping symbols to retail addresses. A literal-binding checker confirms float and string constants point at the right values. Relocation-masked matches, clang-only checks and skeletons don't count. VC6 is the authority, run natively or under Linux via wibo. Attribution uses several independent clues: __FILE__ cross-references, the alphabetical link-order bracket, .CRT$XCU initializer order, and the per-file $E sets that build the four kVec3 constants in nearly every translation unit, with 580 cases audited. Code is promoted into src/krusty2 only when the file name is attested, the code sits inside its bracket, and it references its own __FILE__. The canary for operand-order flips is TrackGame slot 1's availPhys + availPageFile.
