06

The boot path is mostly reconstructed. WinMain at 0x4a0bc0 wraps everything in structured exception handling. PCGame::StartUp maps the "Renderer" setting to a device GUID, enumerates displays, and re-profiles stale per-driver profiles; the profiling pass tests whether ten 256x256 textures fit. The Game initializer creates two root GameObjects, PCSoundInterface and TextureMapManager, and a DebugOverlay only when an XOR-obfuscated "TestKey" registry value is set. It also seeds srand from the timestamp counter. TrackGame's virtual slots then do the game-specific work: slot 1 for startup checks, slot 3 to mount ten resource archives, slot 4 to build scene, audio, collision, input mapping, the UI and the EventManager.
