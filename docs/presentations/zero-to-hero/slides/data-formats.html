Two text readers: [section] key=value blocks, and <Tag>value</Tag> lists.

Light obfuscation: "FAOE" files XOR with a key seeded from the file name.

Source: PARAMETERBLOCKS, PARSER, FILESTREAM, RESOURCEMANAGER docs

19

A quick map for modders and reverse engineers. The ten Res archives use an "RS2" tag and are managed by ResourceManager. Parameterblocks.cpp reads INI-style sections with key=value or comma rows of up to 16 values, semicolon comments and T/F/ON/OFF/Y/N booleans; it reads .pb files, presets.pb and the "General info" sections of .slt models. Parser.cpp reads tag-style lists with case-insensitive keys. FileStream can read a whole file or a slice of an archive, and decodes "FAOE"-headed files with a running XOR key. The .mcf description is based on the names that appear, UIgarage.mcf, UIRider.mcf and Winner.mcf; the docs don't define the format. Scene "scn" grammar beyond SceneManager's section keys isn't documented yet.
