Four kinds of remaining work, now that the game links and races. First, near misses: 351,255 bytes across 211 registered functions, concentrated in the big loaders. Second, inline assembly: 33 functions and 42,650 bytes that use rdtsc, fistp or fs:[4], which the current rules exclude; Game slot 10's timer, vertex lighting and GridNode's ray cast are among them. Third, stand-ins: the running build uses best-guess bodies where no matching source exists yet, such as terrain's per-frame prepare, and each is a candidate to byte-match later. Fourth, names and translation-unit boundaries: almost all method and member names are reconstruction names, and several file boundaries remain ambiguous.
