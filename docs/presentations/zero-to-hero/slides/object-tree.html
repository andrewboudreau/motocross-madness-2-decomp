08

This is the spine of the engine. BaseObject is a tiny COM-like refcount, and it is the README's recommended starting point because all six of its functions match VC6 output byte for byte. GameObject adds an intrusive tree. Update, render passes, input and network messages are all virtual calls that walk this tree: update is slot 10 with a float dt, input arrives as slots 22/23, network messages as slot 24 with type, data, from, to and flags. Every constructor level appends typeid(*this).name() to a heap string, so an object can be found by class name at runtime. KrustyBike reaches GameObject as a virtual base through the Vehicle chain, which is why it has three vtables.
